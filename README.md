# Tihonizy

Machine learning and data science. I take part in Kaggle competitions on computer vision and
tabular data and build projects end to end, from data analysis to a deployed model.

Kaggle: [tihon2010](https://www.kaggle.com/tihon2010)

## Projects

| Repository | Description |
|---|---|
| [kaggle-deep-learning](https://github.com/Tihonizy/kaggle-deep-learning) | PyTorch solutions to Kaggle computer vision competitions: digit classification with custom CNNs, and knee MRI abnormality detection with DINOv2, labels derived from radiology reports and attention over MRI series |
| [kaggle-classic-ml](https://github.com/Tihonizy/kaggle-classic-ml) | Tabular Kaggle competitions: Titanic, House Prices and Hull Tactical market prediction with feature engineering, CatBoost and Hyperopt |
| [sentiment-api](https://github.com/Tihonizy/sentiment-api) | FastAPI service that classifies Russian-language reviews, deployed on Render |
| [skillfactory-ds](https://github.com/Tihonizy/skillfactory-ds) | Data science course projects: visualization, SQL, hypothesis testing, RFM clustering and NLP |
| [pytorch-learning](https://github.com/Tihonizy/pytorch-learning) | PyTorch fundamentals: custom datasets, models from scratch, transfer learning and experiment tracking |

## Currently working on

[RSNA Knee Abnormality Detection](https://github.com/Tihonizy/kaggle-deep-learning/tree/main/rsna-knee-abnormality-detection):
scoring 12 findings on knee MRI studies when only 58 of 4,407 studies are labelled, by extracting
labels from multilingual radiology reports and training a multiple instance model over MRI series.
